AI Creating

Realizei a criação de um modelo de IA com base em um dataset de preços de casas na Califórnia. Foi utilizado LinearRegression para treinar o modelo para identificar valores lineares com base no preço médio da casa, quantidade de cômodos e população da cidade onde está localizada a casa.

Esse modelo obteve um score satisfatório de 61% de performance, sendo necessário aprimorar e otimizar ele para chegar em 90%+.
